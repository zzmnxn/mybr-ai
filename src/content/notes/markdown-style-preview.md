이 문서는 **디자인 확인을 위한 예시**입니다. 실제 경험이나 검증 결과를 기록한 글이 아닙니다. 아래 내용을 스크롤하며 문법별 스타일과 글을 읽을 때의 간격을 확인해 보세요.

# 제목과 본문

## 두번째
본문은 생각을 차분히 따라갈 수 있어야 합니다. 문장이 길어져도 한글의 어절이 자연스럽게 이어지고, 문단 사이에는 잠깐 쉬어 갈 여백이 남습니다. 화면이 좁아지면 이 문장이 어떻게 줄바꿈되는지도 살펴보세요.

두 번째 문단입니다. **강조한 문장에는 데님 블루 형광펜**이 그어집니다. *기울임 문법으로 작성한 강조*와 일반 문장의 차이, 그리고 ~~취소한 문장~~의 색도 함께 비교할 수 있습니다.

### 세 번째 수준의 제목

큰 주제 안에서 내용을 나누는 소제목입니다. 본문과의 크기 차이, 제목 아래 구분선과 위아래 여백을 확인합니다.

#### 네 번째 수준의 제목

더 작은 단위의 설명입니다. 밑줄 대신 제목 왼쪽의 작은 데님 블루 점을 확인합니다.

##### 다섯 번째 수준의 제목

보조 설명을 묶는 작은 제목입니다.

###### 여섯 번째 수준의 제목

가장 작은 제목도 본문과 구분되면서 차분하게 읽히는지 확인합니다.

## 인용문

> 기록은 생각을 붙잡는 일이고, 연결은 그 생각을 다시 발견하는 일이다.

인용문 바깥의 본문입니다. 인용문과 일반 문단 사이의 간격을 비교해 보세요.

> **강조가 들어간 인용문**입니다.
>
> 여러 문단을 넣어도 배경과 왼쪽 강조선이 하나의 덩어리로 이어져야 합니다.
>
> - 인용문 안의 목록
> - `inline code`도 함께 사용할 수 있습니다.
>
> > 한 단계 더 들어간 중첩 인용입니다.

## 링크와 인라인 요소

기존 글로 이동하는 [내부 링크](../astro-basics)와 외부 사이트로 연결되는 [예시 링크](https://example.com)를 비교합니다. 내부 링크는 데님 블루 실선 밑줄, 외부 링크는 점선 밑줄과 ↗ 표시로 구분합니다. 링크 위에 포인터를 올리거나 키보드로 초점을 옮겨 보세요.

파일 이름 `src/styles/global.css`, 명령어 `npm run build`, 속성 `publication: published`는 문장 안에서 배경으로 구분합니다.

HTML 인라인 요소도 사용할 수 있습니다. <mark>직접 표시한 하이라이트</mark>, <kbd>Ctrl</kbd> + <kbd>K</kbd>, 물의 화학식 H<sub>2</sub>O, 제곱 표기 x<sup>2</sup>를 확인해 보세요.

## 코드블록

### TypeScript

언어 라벨, 구문 색상, 복사 버튼과 코드의 행간을 확인합니다. 아래 코드는 문법 표시를 위한 예시입니다.

```typescript
type Note = {
  title: string;
  topics: string[];
};

const note: Note = {
  title: '작은 생각을 연결하기',
  topics: ['Markdown', '디자인'],
};

function describe(note: Note): string {
  return `${note.title} · ${note.topics.join(', ')}`;
}

console.log(describe(note));
```


## 목록

### 순서 없는 목록

- 단순한 항목입니다.
- **강조**와 `코드`가 포함된 항목입니다.
- 문장이 길어져 두 줄 이상이 되었을 때 들여쓰기와 줄 사이의 간격이 자연스럽게 유지되는지 확인하기 위한 항목입니다.
  - 두 번째 깊이의 항목
  - 같은 깊이의 또 다른 항목
    - 세 번째 깊이의 항목

### 순서 있는 목록

1. 문서에서 제목과 본문을 읽습니다.
2. 인용문과 코드블록을 비교합니다.
   1. 짧은 코드를 확인합니다.
   2. 긴 코드의 가로 스크롤을 확인합니다.
3. 화면 폭을 바꾸어 간격을 살펴봅니다.

### 체크리스트

아래 상태는 문법 예시이며 실제 작업 완료를 의미하지 않습니다.

- [x] 체크된 항목
- [ ] 체크되지 않은 항목
- [ ] **강조 문구**와 `인라인 코드`가 있는 항목

| 요소 | 표현 | 확인할 점 |

### 열 너비와 정렬

표는 본문 너비를 채우고 열 수에 맞춰 균등하게 나눕니다. 두 열이면 각각 절반을 차지합니다.

| 짧은 제목 | 긴 제목과 설명 |
| --- | --- |
| A | 내용 길이가 달라도 두 열은 같은 너비를 차지합니다. |
| `code` | very-long-unbroken-text-for-checking-table-cell-wrapping-on-small-screens |

| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
| :--- | :---: | ---: |
| 짧은 값 | 예시 A | 12 |
| 조금 더 긴 값 | 예시 B | 1,024 |
| `inline code` | **강조** | 36 |

| 항목 | 첫 번째 비교 기준 | 두 번째 비교 기준 | 세 번째 비교 기준 | 네 번째 비교 기준 |
| --- | --- | --- | --- | --- |
| 예시 A | 제목 주변의 충분한 여백 | 문장과 강조선의 거리 | 긴 내용의 자연스러운 줄바꿈 | 좁은 화면에서 셀 안 줄바꿈 |
| 예시 B | 표 머리글의 배경색 | 번갈아 나타나는 행 배경 | 테두리의 굵기와 모서리 | 본문 영역 안에서 유지되는 폭 |
